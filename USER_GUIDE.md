# EventYatwon User Guide

EventYatwon is an event discovery, registration, ticketing, and event-management platform. Visitors can explore public events, attendees can register and receive digital tickets, organizers can publish and operate events, and administrators can oversee the platform.

This guide describes the features currently available in EventYatwon.

## 1. Account types

EventYatwon has three account roles.

| Role          | Main purpose                                                                                       | How the account is created                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Visitor       | Browse published events, organizers, reviews, the calendar, help articles, and support             | No account required                                                                          |
| Attendee      | Register for events, receive tickets, save events, get recommendations, and write eligible reviews | Select **Attendee** on the public registration page                                          |
| Organizer     | Create, publish, update, analyze, and operate events                                               | Select **Organizer** on the public registration page                                         |
| Administrator | Monitor users, events, categories, and platform activity                                           | Created privately by the system administrator; admin is not available on public registration |

Permissions are enforced by the server. A user cannot access another role's protected functions simply by entering a protected URL.

## 2. Getting started

### Create an account

1. Select **Create account** or **Register** in the navigation.
2. Enter your name and email address.
3. Create a password. It must be 8 to 72 bytes long and contain an uppercase letter, a lowercase letter, and a number.
4. Enter the password again.
5. Choose **Attendee** or **Organizer**.
6. Select **Create account**.

Use an attendee account if you want to join events. Use an organizer account if you want to create and operate events. The account role is not changed from the profile page.

### Log in

1. Select **Log in**.
2. Enter the email address and password used for your account.
3. Select **Log in**.

After login, use the account menu in the top navigation or the account sidebar to open role-specific pages.

### Log out

Open the account menu and select **Log out**. Logging out removes private cached account information from the browser.

## 3. Public website and event discovery

These features are available without an account.

### Home page

The home page provides:

- Event search
- Category shortcuts
- Platform statistics
- Featured event highlights
- An explanation of how EventYatwon works
- Links for attendees and organizers

### Explore events

Open **Explore events** to browse published events. Available controls include:

- Search by event title
- Filter by category
- Filter by date
- Filter by minimum and maximum ticket price
- Sort by event date or newest event
- Move between result pages

Select an event card to open its event details.

### Event calendar

Open **Calendar** to browse published events by month.

- Select the left or right arrow to change month.
- Select **Today** to return to the current month.
- On larger screens, select an event inside a calendar day.
- On smaller screens, use the date-grouped event agenda.
- Select **Browse all events** to return to the complete event list.

Events that run across more than one date appear on each applicable calendar day.

### Event details

An event page can show:

- Banner, title, category, and status
- Start and end date and time
- Organizer name and public organizer profile
- Organizer contact email for signed-in attendees and organizers
- Number registered and total capacity
- Venue name, address, and a Google Maps link
- Full event description
- Ticket types, prices, and remaining availability
- Public ratings and reviews

Only attendees can register. Organizers and administrators see management actions when they are authorized to manage the event.

### Organizer public profile

Select an organizer's name on an event page to view their public profile. The profile shows:

- Organizer name and profile image
- Date joined
- Number of published events
- Total registrations across published events
- The organizer's published event list

Private account information is not displayed on the public organizer profile.

### About page

The **About** page explains EventYatwon's purpose, approach, and community benefits.

### Help Center

The **Help Center** contains searchable answers about:

- Event registration
- Tickets and check-in
- Events and accounts

Enter a word or phrase in the search box to filter the help articles.

### Contact Support

Visitors and signed-in users can submit a support request.

1. Open **Contact support**.
2. Enter your name and email address. These are filled automatically when you are signed in.
3. Choose a topic: registration, tickets and check-in, account, event management, or something else.
4. Describe the issue. Include the event name, what you tried, and any error message.
5. Select **Send request**.

The request is stored and active administrators are notified.

## 4. Features available to every signed-in user

### Account settings

Open **Account settings** or **Profile** to manage your account.

#### Update name or email

1. Edit the name or email fields.
2. Select **Save changes**.

Your name is used on registrations, tickets, and reviews. Use an email address you can access.

#### Add or change a profile image

1. Select the profile image preview.
2. Choose a JPEG, PNG, WebP, GIF, or AVIF image up to 5 MB.
3. Review the preview.
4. Select **Save image**.

To remove the current image, hover or focus the image, select the delete icon, and confirm removal.

### Saved events

Use the heart control on an event card or event page to save or unsave an event. Open **Saved events** to view the complete saved list.

Saving an event does not register you for it or reserve tickets.

### Notifications

The notification bell shows the unread count. The Notifications page supports:

- Opening a notification's related page
- Marking an individual notification as read
- Marking all notifications as read
- Deleting an individual notification
- Deleting all notifications after confirmation

Notifications may be created for registration activity, ticket activity, event changes, cancellations, and system messages.

## 5. Attendee guide

### Attendee dashboard

Open **Overview** to see a summary of your account:

- Upcoming events
- Active tickets
- Saved events
- Recent activity such as registrations, saved events, and check-ins

### Recommended events

Open **Recommended** to see personalized published events. Recommendations use categories from your registrations and saved events. Events for which you already have a registration are excluded.

If you are new to EventYatwon, save or register for events to make recommendations more personal.

### Register for an event

1. Open a published event.
2. Select **Register now**. If you are signed out, the button asks you to sign in first.
3. Choose an available ticket type.
4. Use the plus and minus controls to choose a quantity.
5. Review the price, remaining availability, and total.
6. Select **Confirm registration**.

EventYatwon checks all of the following before confirming:

- The event is published and has not ended or been cancelled.
- Event capacity is available.
- The selected ticket type is valid.
- The selected ticket type has enough tickets remaining.
- You do not already have a registration for the same event.

After success, the confirmation page shows the ticket type, quantity, event date, venue, and registration ID.

### My Events

Open **My events** to view registrations grouped into:

- Upcoming events
- Past events
- Cancelled registrations

Open a registration to review its details. An upcoming registration can be cancelled while the event is still active and has not started. Cancelled history can be removed from your personal list without deleting the event.

Cancelling a registration invalidates its associated ticket and restores the event and ticket-type availability.

### My Tickets

Open **My tickets** to view your digital tickets. Each ticket includes:

- Event name, date, and venue
- Attendee name
- Ticket type
- Ticket status
- Check-in status
- Unique ticket code
- Secure QR code

Select **View ticket** for the detailed ticket page and PDF download. Present the QR code or ticket code when entering the event.

Do not share your QR token publicly. A cancelled, expired, or already-used ticket is not valid for entry. Cancelled tickets may be removed from the My Tickets history.

### Cancel a registration

1. Open **My events** or the registration confirmation page.
2. Select **Cancel registration**.
3. Confirm the action.

Cancellation is unavailable after the event starts, after it is completed, or when the event or registration is already cancelled.

### Reviews

Public reviews can be read by everyone. To write a review, you must:

- Be signed in as an attendee
- Have a registration for the event
- Wait until the event has ended

To publish a review:

1. Open the completed event.
2. Go to **Reviews**.
3. Choose a rating from 1 to 5 stars.
4. Enter a comment.
5. Publish the review.

You can edit or delete your own review. Only one review per attendee is shown as the attendee's review for that event.

## 6. Organizer guide

### Organizer event list

Open **My events** in the organizer account menu. You can:

- Search your events
- Filter by draft, pending, published, completed, or cancelled status
- See registration counts and capacity
- Edit an event
- Permanently delete your own draft event after confirmation
- Open event management
- View a published public event page

### Create an event

Open **Create event**. The form is divided into steps:

1. **Basics**: title, category, and description
2. **Date & Time**: start and end date and time
3. **Venue**: venue name and full address
4. **Tickets & Capacity**: total capacity plus one or more ticket types, prices, and quantities
5. **Banner**: upload an image or provide a public image URL
6. **Preview**: review the event before saving

Important rules:

- The end date must be after the start date.
- Capacity must be at least one.
- Combined ticket-type quantities cannot exceed event capacity.
- Ticket names are required and should be unique within the event.
- Uploaded event banners must be an image and no larger than 8 MB.

At the final step, choose:

- **Save as draft** to keep the event private while editing.
- **Create event** to save it as published.

### Public organizer identity

Your name, profile image, joining date, published-event count, registrations, and published events appear on your organizer profile. Keep your name and image current in **Account settings**.

### Event management

Select **Manage** for one of your events. Event management contains six tabs.

#### Overview

The Overview tab shows:

- Capacity
- Total registrations
- Tickets issued
- Checked-in attendees
- Remaining capacity
- Revenue for paid ticket types
- Schedule and venue
- Ticket-type availability breakdown

#### Attendees

The Attendees tab lists registered users. You can search by name, email, or code and filter by registration status. The table shows attendee, ticket type and quantity, registration status, and check-in state.

#### Tickets

The Tickets tab lists issued tickets. You can search and filter by active, used, cancelled, or expired status. The table includes ticket code, attendee, ticket type, status, and check-in state.

#### Check-ins

The Check-ins tab shows completed check-ins with attendee information, ticket code, ticket type, and check-in time. Select **Open scanner** to check in more attendees.

#### Analytics

The Analytics tab provides:

- Registration, ticket, revenue, and check-in summaries
- Ticket-type performance
- Registration activity over time
- Checked-in versus not-checked-in comparison
- Registration and cancellation statistics
- Average tickets per registration

#### Settings

The Settings tab allows authorized organizers to:

- Edit title, category, description, schedule, venue, capacity, and ticket types
- Upload, replace, or remove the event banner
- Publish an event that is currently a draft or pending
- Open the public event page when published
- Open the ticket scanner

Ticket types that already have sales cannot be silently removed or renamed. Changes to important event details can notify registered attendees.

### Check in attendees

Open the scanner from Event Management or the public event page.

#### Scan a QR code

1. Select **Start camera**.
2. Allow camera access when the browser asks.
3. Point the camera at the EventYatwon ticket QR code.
4. Wait for the check-in result.

#### Enter a ticket manually

If the camera is unavailable:

1. Enter the ticket code or ticket ID in the manual field.
2. Submit it for validation.

The scanner verifies that the ticket belongs to the selected event and is active. It rejects unknown, cancelled, inactive, wrong-event, or previously checked-in tickets. A successful check-in marks the ticket as used and records the check-in time.

## 7. Administrator guide

Administrator accounts are created through the private administration process, not public registration. The server protects every admin endpoint with authentication and the admin role.

### Sign in as administrator

1. Open **Log in**.
2. Enter `admin@gmail.com` as the email address.
3. Enter the administrator password supplied privately by the system owner.
4. Select **Log in**.
5. Open the account menu and select **Admin dashboard**.

The Admin Dashboard provides access to **Overview**, **Users**, **Events**, and **Categories**. Do not publish or commit the administrator password. If a password has been shared publicly, change it before deploying the application.

### Admin Overview

The Overview page displays platform totals for:

- Users
- Organizers
- Attendees
- Events
- Registrations
- Tickets

It also shows recent platform activity.

### Users

The Users page supports:

- Search by name or email
- Filter by attendee, organizer, or admin role
- Filter by active or inactive status
- View a user's registration, ticket, and organized-event totals
- Activate or deactivate an account after confirmation

Deactivating an account prevents normal access but does not delete the user or related historical records.

### Events

The Events page supports:

- Search by event title
- Filter by event status
- Filter by category
- View organizer, date, venue, registrations, and capacity
- Open the full event-management view
- Cancel an event after confirmation

When an administrator cancels an event, registered attendees are notified.

### Categories

The Categories page displays categories derived from existing event records, including total events and published events per category. Categories are not managed as a separate collection in the current system.

### Admin access to event operations

Administrators may open event management and the check-in scanner for platform events. This is intended for oversight and support. Admin actions remain subject to backend authorization.

## 8. Event, registration, and ticket statuses

### Event statuses

| Status    | Meaning                                                                        |
| --------- | ------------------------------------------------------------------------------ |
| Draft     | Private organizer work in progress                                             |
| Pending   | Waiting state before publication                                               |
| Published | Publicly discoverable and eligible for registration while availability remains |
| Completed | Event has finished                                                             |
| Cancelled | Event will not proceed and is unavailable for registration                     |

### Registration statuses

| Status    | Meaning                                                  |
| --------- | -------------------------------------------------------- |
| Pending   | Registration is being processed or awaiting confirmation |
| Confirmed | Registration is valid                                    |
| Cancelled | Registration was cancelled                               |
| Refunded  | Registration was reversed and is no longer valid         |

### Ticket statuses

| Status    | Meaning                                                 |
| --------- | ------------------------------------------------------- |
| Active    | Valid for check-in                                      |
| Used      | Successfully checked in                                 |
| Cancelled | Invalid because its registration or event was cancelled |
| Expired   | No longer valid for entry                               |

## 9. Help and support

Before sending a request:

1. Search the **Help Center**.
2. Reopen the relevant event, registration, or ticket and check its current status.
3. Refresh the page once if information appears outdated.

For event-specific questions, signed-in attendees and organizers can use the organizer email shown on the event details page. For platform issues, use **Contact support**.

Useful details to include in a support request:

- Event name
- Registration ID or ticket code, when relevant
- What you expected to happen
- What actually happened
- The exact error message
- Browser and device type

Never include your password or full QR token.

## 10. Security and privacy

- Passwords are hashed and are not stored as plain text.
- Authentication and role checks are enforced by the backend.
- Ticket QR tokens are unique and should be treated as private.
- Do not post ticket screenshots or QR codes publicly.
- Only use the organizer email for legitimate questions about the related event.
- Log out after using a shared device.
- Deleting an item from personal cancelled history does not delete unrelated platform data.
- Support requests should not contain passwords, complete QR tokens, or unnecessary personal information.

## 11. Troubleshooting

### I cannot register for an event

Check whether:

- You are logged in with an attendee account.
- The event is published and has not started, completed, or been cancelled.
- The event or selected ticket type is sold out.
- You already registered for this event.
- The selected quantity exceeds remaining capacity.

### I cannot find my ticket

Open **My tickets** and check whether the registration was cancelled. Also open **My events** to confirm the registration exists. Refresh the page if the registration was just completed.

### My QR code does not work

Confirm that the ticket status is **Active** and that it is being scanned for the correct event. The organizer can enter the visible ticket code manually if camera scanning fails.

### The camera scanner will not start

- Allow camera permission for EventYatwon in the browser.
- Close another application that may be using the camera.
- Try a supported modern browser.
- Use manual ticket-code entry as a fallback.

### I cannot write a review

Reviews are only available to registered attendees after the event ends. You cannot review an event using an organizer or administrator account.

### I cannot see an organizer or admin page

Confirm that you are signed in with the correct role. Attendee, organizer, and administrator areas have different permissions.

### My changes are not visible

Wait for the save confirmation, then refresh the relevant page. If the issue continues, submit a support request with the page name and any error shown.

### I received an internal server error

Select **Try again** once. If it continues, contact support and include the page, action, event name, and exact error message. Do not include your password or full ticket QR token.
